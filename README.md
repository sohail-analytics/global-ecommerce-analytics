# Global E-commerce Analytics
**End-to-end E-commerce Data Analytics Project using Excel, MySQL, Tableau and Power BI**
## Project Overview
This project focuses on analyzing global e-commerce sales data to understand business performance, profitability, customer segments, product categories, and shipping operations.
The project follows an end-to-end analytics workflow, from data preparation and SQL analysis to interactive dashboard development and business recommendations.

## Business Objectives
- Analyze overall sales and profit performance.
- Identify profitable and underperforming product categories.
- Compare sales and profitability across markets and customer segments.
- Understand order trends and shipping performance.
- Develop interactive dashboards to support business decision-making.

## Tools and Technologies
| Microsoft Excel - Data cleaning, PivotTables, KPI analysis and dashboards |
| MySQL - Database management, SQL queries, data validation and business analysis |
| Tableau - Interactive dashboards and data visualization |
| Power BI - Power Query, data modeling, DAX measures and advanced analytics |

## Dataset Overview
The project uses the Global Superstore dataset, containing three main datasets:
- **Orders:** Sales transactions, customers, products, shipping and order details.
- **Returns:** Returned order information.
- **People:** Regional manager information.

### Key Dataset Metrics
| Order-line records - 51,313 |
| Distinct orders - 25,035 |
| Total sales - $12,643,332.95 |
| Total profit - $1,467,402.45 |
| Total quantity - 178,379 |
| Profit margin - 11.61% |
| Return records - 1,173 |
| People records - 13 |
*These are project baseline figures. Profit margin is calculated as total profit divided by total sales.*
